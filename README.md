🌤️ Smart Weather Planner 📌 Overview

Smart Weather Planner is a responsive web application that helps users plan their day based on real-time weather conditions. It fetches live weather data using a weather API and provides current weather, temperature, humidity, wind speed, and forecasts through a clean and user-friendly interface.

✨ Features 🌍 Search weather by city 🌡️ Real-time temperature and weather conditions 💧 Humidity and wind speed 📅 Weather forecast 📱 Responsive design ⚡ Fast API integration 🎨 Simple and modern UI 🛠️ Technologies Used HTML5 CSS3 JavaScript (ES6) Weather API 📂 Project Structure Smart-Weather-Planner/ │── index.html │── style.css │── script.js │── assets/ │── README.md
